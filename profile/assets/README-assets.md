# Assets Directory
This directory contains the official graphical resources of **Sylith Technologies**.
All files stored here represent the visual identity of the organization and may be used across official websites, GitHub repositories, documentation, presentations, and other communication materials.

## Purpose
The purpose of this directory is to provide a centralized location for reusable visual assets, ensuring consistency across the entire Sylith ecosystem.
Unless otherwise stated, assets in this directory are intended for official Sylith Technologies projects only.

# Design Principles

Every asset should follow the visual principles defined in the **Sylith Design Language (SDL)**.

These include:

* visual consistency;
* minimalism;
* readability;
* accessibility;
* modern aesthetics;
* high-resolution output.



# Preferred Formats

Whenever possible, assets should be provided in vector format.

Preferred formats:

* SVG
* PNG (lossless)
* WebP (optimized raster)

Avoid storing editable project files unless necessary.



# Naming Convention

File names should:

* use lowercase letters;
* use hyphens instead of spaces;
* avoid version numbers in filenames;
* remain descriptive.

Examples:

```
logo.svg
logo-dark.svg
banner-light.svg
weather-icon.svg
```



# Contributions

Changes to official visual assets should preserve the identity of Sylith Technologies.

Contributors are encouraged to:

* avoid unnecessary redesigns;
* maintain visual consistency;
* follow the SDL documentation;
* submit high-quality source files whenever applicable.
