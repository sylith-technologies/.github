
# Sylith Technologies Group
### Made for confort. Made for everyone.

*Building modern, coherent and integrated software ecosystem for Linux.*

---

## About
**Sylith Technologies** is an independent software development organization focused on creating high-quality applications, shared technologies and, in the future, a Linux ecosystem.
Our pilosophy is simple:
> Software should be comfortable, powerful and accessible without sacrificing stability, privacy or user freedom.
Rather than developing isolated applications, Sylith builds an integrated ecosystem.

# Mission

Develop moder, useful and accessible software that combines:
- High quality
- Visual consistency
- Strong privacy
- Performance
- Modularity
- Long-term maintainability
while protecting community work from unauthorizated commercial exploitation.

# Vision
Our long-term vision is to build a complete Linux ecosystem composed of:
- Native desktop applications
- Shared development libraries
- Unified desing language
- Developer SDK
- Official repositories

# Phylosophy
Sylith believes that modern software should be:
- Beautiful without unnecessary complexity
- Powerful without becoming difficult
- Customizable without compromising stability
- Open for collaboration while protecting authorship
- Respectful of user privacy

# Core Principles
- Consistency
  - Applications shoud feel like parts of the same family.
- Integration
  - Software should cooperate instead of existing as isolated tools.
- Privacy
  - Users own their data.
  - Telemetry, when available, must always be transparent and optional.
